
# Git

Git is an open source distributed version control system. It maintains a local copy of the entire repository with history and version-tracking abilities.

## Installation

To install Git follow the next steps:

- [Click here](https://git-scm.com/install/windows) and download the installer for the latest Git version for Windows.
- Open the installer and use the installer suggested options.
    - We suggest you install Git in `C:\Programs\Git`.
- Ensure the following values are included in `Path`:
    - `C:\Programs\Git\bin`
    - `C:\Programs\Git\cmd`

To confirm the installation, run `git --version` in Powershell or any other terminal. If the installation was successful you should see something similar to
```
git version 2.54.0.windows.1
```
